# Crop Resilience Challenge

This folder contains the static website **Can Our Crops Survive the Drought?**

## Publish with GitHub Pages

1. Extract the ZIP file on your computer.
2. Create a new public GitHub repository named `crop-resilience-challenge`.
3. Upload `index.html` and this `README.md` to the repository root.
4. Open the repository's **Settings** and select **Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select the `main` branch and the `/(root)` folder, then save.
7. Wait a few minutes for GitHub to display the public website address.

Do not upload the ZIP file by itself. GitHub Pages must be able to see
`index.html` in the selected publishing folder.
